## 📖 Açıklama

**TR:** Compass — İlham Pusulam, içerik üreticileri için tasarlanmış kapsamlı bir mobil/web uygulamasıdır. Nişini seç, yapay zekâ ya da hazır içerik havuzundan fikirler al, haftalık planını oluştur, performansını analiz et, hatırlatıcılarla üretim takibini sürdür. 100 farklı araçla içerik üretim sürecinin her adımında yanında.

**EN:** Compass — İlham Pusulam is a comprehensive mobile/web app for content creators. Pick your niche, get ideas from AI or a curated pool, plan your week, analyze performance, and stay consistent with reminders. 100 tools covering every step of the content creation workflow.

🎯 **Hedef kitle:** Solo creator'lar, niş influencer'lar, küçük işletme sosyal medya yöneticileri.

## 🎨 Design System

Modüler, tema-duyarlı tipografi/renk/spacing altyapısı. Tüm dosyalar `styles/` altında.

### Renk Paleti
Pastel + canlı accent'ler (Hootsuite/Buffer/Spotify/Slack ilhamı). Light + dark varyantları.

| Token | Light | Dark | Kullanım |
|-------|-------|------|----------|
| `primary` | `#4D96FF` | `#60A5FA` | Ana aksiyon, CTA, aktif sekme |
| `primarySoft` | `#DCE9FF` | `#1E3A66` | Vurgu arka planı, chip/ghost pressed |
| `secondary` | `#B79DFF` | `#C4B5FD` | İkincil vurgu (mor pastel) |
| `accent` | `#FF6FA1` | `#FF8FB6` | Eğlenceli, samimi vurgu (pembe) |
| `bg` / `surface` / `card` | farklı açıklık | koyu tonlar | Sayfa yüzeyi / kart yüzeyi |
| `text` / `textMuted` | `#0F172A` / `#6B7280` | `#F1F5F9` / `#94A3B8` | Metin hiyerarşisi |

Semantic tonlar (`success`, `warning`, `error`, `info`) her biri `bg`, `text`, `border`, `solid`, `solidText` alanlarıyla gelir. Nötr skala `neutralScale` (50–900) ayrıca export edilir.

### Typography
Display, h1, h2, h3, body, bodySm, caption, label — fontSize + lineHeight + fontWeight + letterSpacing. Platform-bağımsız, sistem font yığını.

### Spacing
4–64 px arası: `xs(4) · sm(8) · md(12) · lg(16) · xl(20) · 2xl(24) · 3xl(32) · 4xl(48) · 5xl(64)`.

### Border Radius
`sm(6) · md(10) · lg(16) · xl(24) · 2xl(32) · full(9999)`.

### Shadows
`sm / md / lg / xl` — `Platform.select` ile iOS shadow + Android elevation + Web boxShadow aynı objede birleşik.

### Bileşen Stilleri
- **Button** — `primary | secondary | ghost | icon`, her biri `default + pressed`, boyutlar `sm | md | lg`.
- **Badge** — `solid | outline`, tonlar `neutral | primary | success | warning | error | info`.
- **Chip** — `default | selected` (seçilebilir etiket).
- **Tag** — kompakt, köşeli etiket.
- **Input** — `default | focused | error | disabled` (container + text + placeholder).
- **Card** — `flat | elevated | outlined`.
- **Modal** — `backdrop | sheet`.

### Tema Kompozisyonu
`createTheme(scheme)` tüm token'ları tek `CompassTheme` objesinde toplar. Hazır: `lightTheme`, `darkTheme`. Mevcut `services/theme.tsx` (React context) bağımsız çalışır — context köprüsü ileride eklenecek.

### Dosya Haritası
```
styles/
├── colors.ts        # lightColors, darkColors, neutralScale
├── typography.ts    # typography + tipleri
├── spacing.ts       # spacing
├── radius.ts        # radius
├── shadows.ts       # shadows (platform-aware)
├── buttons.ts       # createButtonStyles + buttonSizes
├── badges.ts        # createBadgeStyles (badge + chip + tag)
├── inputs.ts        # createInputStyles (input + card + modal)
├── theme.ts         # createTheme, lightTheme, darkTheme
└── index.ts         # barrel export
```

## 🚀 Kurulum

### Gereksinimler
- **Node.js** 18+ ve npm
- **macOS** (iOS geliştirme için Xcode + CocoaPods) — opsiyonel
- **Expo Go** (iOS/Android) — veya web tarayıcı

### 1. Repo'yu klonla
```bash
git clone https://github.com/rainakara83-sudo/compass-ilham-pusulam.git
cd compass-ilham-pusulam
```

### 2. Bağımlılıkları kur
```bash
npm install
```

### 3. (Opsiyonel) Backend proxy ayarla
`.env` dosyası oluştur:
```env
EXPO_PUBLIC_BACKEND_URL=https://YOUR_BACKEND_URL.com
EXPO_PUBLIC_AI_PROXY_URL=https://YOUR_BACKEND_URL.com/api/ask
```
`backend-example/` klasöründe Next.js örneği var.

### 4. Geliştirme sunucusunu başlat
```bash
npx expo start
```
- **iOS:** `i` tuşuna bas (simulator gerekli)
- **Android:** `a` tuşuna bas (emulator gerekli)
- **Web:** `w` tuşuna bas (tarayıcıda açılır)
- **Telefon:** Expo Go ile QR kodu tara

### 5. TypeScript kontrolü
```bash
npx tsc --noEmit
```

## 📦 Build & Deploy

### Web Build (Ücretsiz, Kolay)
```bash
npx expo export --platform web
```
Çıktı: `dist/` klasörü. Tek dosya HTML + JS bundle (≈2.8 MB).

### Netlify'a Deploy (2 yöntem)

**Yöntem 1 — Drag & Drop (en kolay):**
1. https://app.netlify.com/drop adresine git
2. `dist/` klasörünü sürükle-bırak
3. 30 saniyede URL alırsın

**Yöntem 2 — Netlify CLI:**
```bash
npm install -g netlify-cli
netlify deploy --dir=dist --prod
```

### EAS Update (OTA — mevcut kullanıcılara anında güncelleme)
```bash
eas login --token <TOKEN>
eas update --branch production --message "Değişiklik notu" --non-interactive
```
Telefon/Expo Go otomatik günceller.

### EAS Build (Gerçek IPA/APK)
```bash
eas build --profile development --platform ios
```
⚠️ Apple Developer Program ($99/yıl) gerekir.
